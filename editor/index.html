Maps are placed where their doorways say they join, so this is the world as the player walks it. A room you enter through a door is not next to anything, so it sits in a band below with a line back to its doorway.
click a map to open it
Each gate has a colour and a number: the filled band is a mouth, the arrow runs to where it puts you down, and a dashed arrow is a one-way trip.
● where a fresh game starts
A quest is authored in content/quests/. What cannot be read there is whether the world can pay it, because that is a question about every map at once - so each objective says how much of what it asks for is placed.
